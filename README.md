# Сайт Авроры

Исходный код [xoxoaurora.ru](https://xoxoaurora.ru/). Начальная версия взята из опубликованного деплоя Vercel: `by-lws/auroras-room`, ветка `main`, коммит `e988da2`. Этот репозиторий пока не подключён к действующему проекту Vercel.

## Запуск и сборка

Нужны Node.js 24 и pnpm 11.19.0.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Откройте `http://localhost:3000`. Для проверки production-сборки выполните `pnpm build`, затем `pnpm start`.

Сайт собирается без секретов. Переменные для тестовой оплаты перечислены в `.env.example`; для интеграционного теста используйте отдельные тестовые настройки и серверное окружение. Не добавляйте `.env.local` и данные клиентов в Git. Доступность оплаты на preview зависит от настройки разрешённого домена, тестового магазина и базы.

Страницы находятся в `src/app`, каталог услуг — в `src/lib/astro/catalog.ts`. Предлагайте правки из отдельной ветки через pull request.
